# 자율주행 데이터 취득 네비게이션 — Ver.3 (TMAP)

Ver.1(main)의 **기본 기능만** 남기고, 지도와 경로 생성을 **전부 TMAP API로 교체한** 버전입니다.
Ver.2(`Thanks-to-SOOHEON00`)의 확장 기능은 이 브랜치 위에 차례로 얹어 갈 예정입니다.

| 버전 | 브랜치 | 지도 | 경로 |
|------|--------|------|------|
| Ver.1 | `main` | Leaflet + OpenStreetMap | OSRM |
| Ver.2 | `Thanks-to-SOOHEON00` | Leaflet + OpenStreetMap | OSRM + HD 도로 데이터 |
| **Ver.3** | **이 브랜치** | **TMAP Vector Map (JS SDK v2)** | **TMAP 자동차 경로안내 API** |

## 기술 구성

| 구분 | 사용 기술 |
|------|-----------|
| 화면 | HTML5, CSS3, JavaScript (단일 파일) |
| 지도 | TMAP JS SDK v2 (`Tmapv2`) |
| 경로 | TMAP 자동차 경로안내 API (`POST /tmap/routes`) |
| 역지오코딩 | TMAP 리버스 지오코딩 API |
| GPS | Browser Geolocation API |
| 음성 안내 | Web Speech API (한국어 TTS) |
| 엑셀 생성 | SheetJS (XLSX) / CSV 폴백 |
| 데이터 저장 | localStorage · sessionStorage |
| 오프라인 | Service Worker |
| 앱 형태 | PWA |

## 시작하기

1. [openapi.sk.com](https://openapi.sk.com) 에서 앱을 등록하고 `appKey`를 발급받습니다.
   활성화가 필요한 상품은 **Vector Map**, **자동차 경로안내**, **리버스 지오코딩** 세 가지입니다.
2. GitHub Pages 등으로 배포한 뒤, SK open API 콘솔에 **배포 도메인을 등록**합니다.
   (등록하지 않으면 SDK 로드와 API 호출이 모두 거부됩니다.)
3. 앱을 열면 첫 화면에서 `appKey`를 입력합니다. 키는 브라우저 `localStorage`에만 저장됩니다.
4. 차량과 이름을 선택하고 입장 → 지역·시나리오 선택 → **▶ 시작**.

> 키를 매번 입력하기 싫다면 `index.html?appKey=발급받은키` 로 한 번만 접속하면 저장됩니다.
> 설정 메뉴의 **🔑 appKey 변경**에서 언제든 다시 바꿀 수 있습니다.

## 구현된 기능 (Ver.1 기본 세트)

- **로그인** — 차량(토레스 1–4호차) · 이름 선택, 세션 유지, 헤더 배지 표시
- **지역·시나리오** — 강남 / 판교 / 시흥 × ㄹ자 그리드 · M자 그리드 · 링 (총 87개 구간)
- **경로** — TMAP 자동차 경로안내로 실제 도로 경로 생성, 지나간 구간 회색 / 남은 구간 파랑
- **턴바이턴** — 지도 위 오버레이(다음 회전·거리·도로명) + 전체 경로 안내 목록
- **음성 안내** — 500 m / 200 m / 50 m 사전 안내, 출발·이탈·도착·휴식, 🔊 음소거 토글
- **GPS** — 실시간 위치·진행 방향, 자동 추적(수동 조작 시 10초 일시정지), 수신 상태 배지
- **자동 진행** — 도착지 50 m 이내 접근 시 구간 완료 → 휴식 타이머 → 다음 구간
- **경로 이탈** — 100 m 초과가 3회 연속되면 경고
- **타이머** — 구간별 주행/휴식 타이머, 5분 남으면 빨간 경고 + 음성
- **주행 기록** — 출발·도착 시각/좌표, TMAP 리버스 지오코딩 주소, XLSX 다운로드(CSV 폴백)
- **설정 내보내기/가져오기** — 주행 기록과 UI 상태를 JSON으로 이식
- **PWA** — 홈 화면 설치, 오프라인 앱 셸

## Ver.1 대비 달라진 점

- **경유점 개수 제한** — TMAP 자동차 경로안내 API는 경유지(`passList`)를 최대 5개까지 받습니다.
  Ver.1의 `WAYPOINTS`(강남 a 시나리오, 최대 6개)는 균등 간격으로 5개까지만 솎아서 전달합니다.
  TMAP은 국내 도로 기준으로 경로를 뽑기 때문에 경유점 없이도 결과가 좋은 편입니다.
  설정 메뉴의 **📍 고정 경유점 사용**으로 켜고 끄며 비교할 수 있습니다.
- **회전 안내 코드** — OSRM의 `maneuver.type/modifier` 대신 TMAP `turnType`을 사용합니다.
  `turnType` 코드표는 문서 버전마다 세부 값이 갈리는 부분이 있어, 확실한 코드만 표(`TURN_TYPE`)로 두고
  나머지는 TMAP이 함께 내려주는 한글 `description`에서 회전 방향을 읽어 보정합니다(`DESC_HINTS`).
  실주행에서 어긋나는 코드가 보이면 이 두 곳만 고치면 됩니다.
- **역지오코딩** — Nominatim 다단계 재시도 → TMAP 리버스 지오코딩 1회 호출로 단순화
- **거리·시간 표기** — 총 거리·예상 시간은 TMAP 응답값, 남은 거리는 경로 좌표 기준 진행률로 계산

## 아직 옮기지 않은 Ver.1/Ver.2 기능

경로 직접 수정(경유점 드래그), 시나리오 편집·구간 추가, 패널 리사이즈, 교통정보 오버레이,
네이버 지도 열기, 밝은 화면 모드, HD 도로 데이터 연동.
